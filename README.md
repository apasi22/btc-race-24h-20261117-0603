Dip-and-ride BTC trading bot: it buys cbBTC when the close is at least 50 bps below the 300-bar mean (unless the 240-bar trend is strongly down), then rides the recovery with an 80 bps trailing stop. Long only, at most one position, fully deterministic — the same bars always produce the same orders.

## Run it

```sh
node main.ts
```

The bot speaks the agent-fun/bars-replay/v1 protocol over stdin/stdout: it reads a hello line and one batch per minute, and answers each batch with its orders.
